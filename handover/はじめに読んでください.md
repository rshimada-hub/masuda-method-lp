# 増田メソッド 個人コンサルティング ページ 公開手順（増田さん用）

このフォルダがページ一式です。Cloudflare という無料のサービスに置くと、そのまま公開されます。
申込フォームの受け口（スプレッドシート記録と通知メール）は設定済みなので、やることは「フォルダをアップロードする」だけです。

---

## いちばん簡単な方法：Claude に任せる（おすすめ）

1. この zip を展開したフォルダを、Claude（デスクトップアプリの Code タブ、または claude.ai/code）で開く
   - Claude デスクトップアプリ → 左上の「Code」→「フォルダを開く」でこのフォルダを選ぶ
2. チャットにこう送る：

   ```
   このフォルダを Cloudflare Pages で公開して。手順は「はじめに読んでください.md」と CLAUDE.md にあります。
   ```

3. あとは Claude の案内どおりに進める。途中で1回だけ、ブラウザで Cloudflare へのログイン（Google アカウントでOK）を求められます。それ以外は Claude が進めます。
4. 最後に `https://〇〇.pages.dev` のURLが出ます。それが公開URLです。

---

## 自分でやる方法：Cloudflare の画面にドラッグ＆ドロップ（約5分）

1. https://dash.cloudflare.com を開き、アカウントを作る（Google アカウントで「Sign up with Google」が早い）。無料プランで足ります
2. 左メニュー「Workers & Pages」→「作成」→ 上のタブで「Pages」→「アセットをアップロード」
3. プロジェクト名を入力（例：`masuda-method`）→「プロジェクトを作成」
4. 「フォルダをアップロード」の枠に、この zip を展開した **フォルダの中身（index.html がある階層）** をドラッグ＆ドロップ
   - zip のまま、またはフォルダをもう一段挟んだ状態だと表示されません。`index.html` と `assets` フォルダが直下に見えている状態で選ぶ
5. 「サイトをデプロイ」→ 数十秒で `https://masuda-method.pages.dev` のようなURLが出る → 開いて確認
6. 確認すること：黒地に金のページが出る／お申し込みフォームにテスト入力して送ると「受け付けました」と出て、申込一覧シートに1行増え、通知メールが届く

### 更新するとき
同じプロジェクトを開き「デプロイを作成」→ 新しいフォルダをドラッグ＆ドロップ。URLは変わりません。

### 独自ドメインにしたいとき
プロジェクト →「カスタムドメイン」→「ドメインを設定」。Cloudflare で管理しているドメインなら自動で設定されます。

## 文言や写真を直したいとき

このフォルダが本番の元データです。Claude でこのフォルダを開き、「〇〇の文章を△△に直して、再公開して」と伝えれば、Claude が `index.html` を直して同じURLに再公開します。増田さんが自分で編集して構いません。
大きな変更（デザインの作り直し・フォーム項目の変更）だけ島田に相談してください。

## 困ったとき

| 症状 | 対処 |
|---|---|

| 申込を送ると「送信できませんでした」 | 一時的な通信エラー。もう一度送る。続くなら島田へ連絡 |
| 画像が出ない | `assets` フォルダが一緒に上がっていない。フォルダごと選び直す |
