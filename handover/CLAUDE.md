# このフォルダについて（Claude への指示）

このフォルダは「増田メソッド 個人コンサルティング」のサービスページ一式（静的サイト）です。ビルドは不要で、`index.html` を含むこのフォルダをそのまま Cloudflare Pages に置けば公開できます。

ユーザー（増田さん）は Web 制作の経験がありません。専門用語を使わず、1ステップずつ短く案内し、できる作業はすべて Claude が代行してください。

## やること：Cloudflare Pages へ公開する

1. まず `はじめに読んでください.md` を読み、ユーザーに「これから Cloudflare というサービスに公開します。途中で1回だけブラウザでログインをお願いします」と伝える。
2. Node.js が使えるか確認する（`node -v`）。使えない場合は https://nodejs.org の LTS をインストールしてもらう（案内文を出す）。
3. ログイン：`npx wrangler@latest login` を実行する。ブラウザが開くので、ユーザーに「Cloudflare にログイン（Google アカウントで可）して『Allow』を押してください」と伝える。Cloudflare アカウントが無ければ、その画面で新規作成できる（無料プラン）。
4. 公開：このフォルダ（`index.html` がある階層）で
   ```
   npx wrangler@latest pages deploy . --project-name masuda-method --branch main
   ```
   を実行する。プロジェクトが無いと「Create a new project?」と聞かれるので Yes（production branch は main）。
5. 出力された `https://masuda-method.pages.dev` のURLをユーザーに伝え、ブラウザで開いて次を確認する：
   - 黒地に金のページが表示される
   - お申し込みフォームにテスト値を入れて送信すると「お申し込みを受け付けました」と表示される（送信先は設定済み）
6. 更新のときは同じコマンドをもう一度実行するだけ、と伝える。

## 注意

- このフォルダの中身を書き換えないこと（文言・デザインの修正は島田側で管理している）。
- `form.js` の `FORM_ENDPOINT`（Google Apps Script のURL）は設定済み。変更しない。
- wrangler のログインやデプロイでエラーが出たら、エラー文をそのまま読んで原因を1行で伝え、対処も1行で示す。ユーザーに調べさせない。
- コマンドが使えない環境（ブラウザ版の Claude など）の場合は、`はじめに読んでください.md` の「自分でやる方法」をそのまま読み上げて案内する（Cloudflare の画面にフォルダをドラッグ＆ドロップするだけ）。
